# EasyRAG 两页知识工作台实施计划

> 首版实施记录，以下步骤已完成。用户随后确认 UI 并要求追加网页模型配置、创建子 Issue 和 PR；交付工作见 [模型配置计划](2026-09-14-model-settings.md)。

**目标：** 交付可在浏览器查看、连接实际后端的「资料 / 问答」第一版，支持上传、核验出处、更新与删除资料。

**架构：** Vue 3 + TypeScript + Pinia；所有业务请求只经过 Spring Boot。Python 继续只负责 RAG 计算。页面沿用两个路由，使用共享详情抽屉查看原文。问答结果保存在 Pinia 中，切换页面不丢失。

**视觉：** 暖灰画布、白色纸面、深绿色强调色；轻量顶栏导航；资料页紧凑，问答页适合阅读。先完成真实交互，模型配置入口按用户后续答复限定范围。
