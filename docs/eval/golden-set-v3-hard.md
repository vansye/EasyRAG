## 二、库外类（0 题）

本集最初把三道"术语在库、内容不在"的词法陷阱题标为库外类（原 N11–N13），首轮在线评估三题全部被判 PARTIAL、答案如实声明缺失。对照判断力记录 #15 的三态标准——PARTIAL 是"有直接相关内容，缺失的是问题主体"，NONE 是"没有与主题直接相关的片段（词面相似不算）"——这三题的片段主题就是所问术语，缺的是主体，判 PARTIAL 才符合契约；v2 的 N8（主从复制 vs 持久化片段）被判 NONE 正说明判定器分得清"主题在不在"。因此改标为部分覆盖类（见二之二 P4–P6），本集不再有库外题；库外能力由 v1 N1–N7、v2 N8–N10 覆盖。

## 五、为什么这 19 题（创建时的裁决记录）

- **难点类型来自真实记录，不是想象**：本机问答历史导出的 10 条失败里有 `checkpiont`（错别字）、`FDE`（缩写）、`git` 小写英文——它们才是普通用户的问法。v1/v2 的问题都是"写得端正"的，测不到这些。
- **词法陷阱题先标错、再由实测纠正**：P4–P6 最初标为库外类（期望 NONE），首轮在线评估三题全部判 PARTIAL，答案都明说"片段未提及、无法回答"并引用片段说明库里有什么，没有编造。按 #15 的三态标准这正是 PARTIAL 的定义，错的是标注不是判定器，于是改标为部分覆盖类并加上"不得编造缺失部分"的附加检验。与 #15 当年单立部分覆盖类是同一件事：评估口径要跟着实测走。
- **错别字题不新增文档**：Q29 / Q30 与既有题同出处，但问法里的错词在语料中零匹配。它们测的是向量通道对错字的容错，与词法无关，所以允许重复出处。
- **两个"专篇压制短卡"**：Q21 之后需要第二、第三个样本才能说这是一类现象而不是一道题；Q31（不含"缓冲区"字样）比 Q21 更难，Q32（Tomcat 短卡 vs 拦截器详解篇）换了一个领域。
- **P 类不凑数**：P3 之外的三题是改标而来，不是为了扩大分母。
- **不出的题**：hz 参数的取舍原文写得够全，当部分覆盖题会被判 SUFFICIENT，不是判定器的错；"prompt / model / parser 为什么能用 | 串起来"在 LCEL 与 Runnable 两篇里都有完整说明，唯一出处不成立。
