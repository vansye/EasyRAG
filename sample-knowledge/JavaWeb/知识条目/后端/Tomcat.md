## 详细

### 概念

Tomcat 是常见的 Java Web 容器，用来部署和运行 [[Servlet]]、JSP 等 Web 程序。它负责接收 HTTP 请求，调用对应的处理逻辑，再把响应返回给浏览器。学习 JavaWeb 时，Tomcat 通常是最先接触的运行环境。


### 重点

- 属于 Web 容器，不是数据库，也不是编译器
- 管理 Web 应用的部署、启动和访问
- 学习 [[Servlet]]、JSP、[[Filter过滤器]] 时通常先接触 Tomcat
